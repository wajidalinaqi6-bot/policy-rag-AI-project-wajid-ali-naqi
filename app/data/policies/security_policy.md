# Information Security Policy

## Password Requirements
- Minimum 12 characters
- Must include: uppercase, lowercase, numbers, special characters
- Change every 90 days
- Cannot reuse last 10 passwords
- Never share passwords with anyone

## Multi-Factor Authentication (MFA)
- Required for all employee accounts
- Required for: email, VPN, cloud services, code repositories
- Authenticator app preferred over SMS
- Backup codes stored securely in password manager

## Data Classification
- **Public**: Marketing materials, published content
- **Internal**: Internal communications, project plans
- **Confidential**: Customer data, financial records, employee information
- **Restricted**: Trade secrets, security credentials, authentication keys

## Acceptable Use
- Company devices for work purposes only
- No unauthorized software installations
- Report suspicious emails to IT security
- Lock computer when leaving desk
- Encrypt sensitive files before sending externally

## Incident Reporting
- Report security incidents immediately to security@company.com
- Do not attempt to fix security issues yourself
- Preserve evidence - don't delete suspicious files
- Incident response team will contact you within 1 hour

## Compliance
- Annual security training required
- Random security audits conducted quarterly
- Violations may result in disciplinary action
